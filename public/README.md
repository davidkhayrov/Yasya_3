# Сайт-поздравление с днём рождения

## Как добавить фотографии

1. Положи свои фотографии в папку `public/` с именами:
   - `photo1.jpg`
   - `photo2.jpg`
   - `photo3.jpg`
   - `photo4.jpg`
   - `photo5.jpg`
   - `photo6.jpg`

2. Чтобы изменить список, подписи или количество фото — отредактируй массив `PHOTOS` в файле `src/components/Gallery.tsx`.

Пока фотографий нет — на их местах показываются аккуратные заглушки с подсказкой.

## Как добавить музыку

1. Положи музыкальный файл в папку `public/` с именем `music.mp3`.
2. Кнопка управления музыкой находится в правом нижнем углу. Музыка не включается автоматически — только по нажатию.

## Как добавить превью для Telegram/WhatsApp

Положи картинку `og-image.jpg` (1200×630px) в папку `public/`.

## Запуск

Проект собирается командой `npm run build` и готов к публикации на Vercel.
